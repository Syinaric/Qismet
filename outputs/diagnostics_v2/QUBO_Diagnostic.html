Qismet: audit the QUBO before scaling¶

This executed notebook reads the diagnostic artifacts produced by run_audit.py. It asks whether QAOA finds the surrogate optimum, whether pairwise interactions improve prediction over a linear-only model, and whether either model selects useful subnetworks.

Scope: original three Two Moons initializations; 8 hidden neurons; retain 4; 128 fit masks and 35 held-out feasible masks per seed. All 70 feasible masks per seed were retrained for 200 full-batch Adam steps, with validation metrics at every epoch. Test data was not evaluated. This is exploratory reuse of the original audit split, not a new confirmatory experiment.

To regenerate underlying measurements, run python run_audit.py in this folder using the original Qismet environment. The script needs the sibling results/ checkpoints and experiment_utils.py; it does not modify them. Then rerun this notebook.

Mask strings are in neuron-index order: a 1 retains that neuron. Hamming distance counts positions that differ. The surrogate gap is measured against the exact minimum over all 70 four-neuron masks. A gap above zero means the finite-shot QAOA selection missed the optimum.

Linear-only versus pairwise surrogate¶

The linear model uses the same original fitting labels, ridge-alpha candidates, and CV splits as the original quadratic model. The quadratic coefficients are reused unchanged. Higher Spearman cost-versus-loss correlation is better; cost-versus-accuracy should be negative. R² below zero means predictions are worse in squared error than the held-out mean.

Selecting masks and retraining¶

all70 selection searches the entire feasible set. audit35 compares surrogate selection on masks whose retraining labels were excluded from fitting. Validation-loss regret is the excess over the best actual validation loss in that same candidate set. The oracle is a retrospective reference, not an independently validated winning network.

QUBO diagnostic: original Two Moons experiment¶

This is an exploratory follow-up on the original three initializations and mask audit split. It reuses existing audit labels; it is not a fresh confirmatory test or a new dataset trial. Test data was not evaluated or used for any audit decisions.

QAOA's selected mask differs from the single random mask in every initialization, and does not equal the exact surrogate optimum in any of the three. The gap is measured in unpenalized predicted validation cross-entropy; all compared masks satisfy the same cardinality.

Do pairwise terms improve prediction?¶

Both models use exactly the same original 128 fitting labels and five-fold CV with the same alpha grid. The 35 held-out feasible masks per initialization are excluded from fitting and CV. All 70 feasible masks were retrained from saved initializations, with exactly the original 200 full-batch Adam steps and fresh optimizer. Final validation losses matched the saved labels within 1e-7. These are descriptions of three initializations, not statistically established advantages. Pairwise features can improve fit without reliably improving selection; read both tables together. A stronger dataset will not automatically repair either surrogate error or QAOA optimization error.
